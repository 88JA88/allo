# Allo !

PWA autonome : un carnet d'appels visuel, installable sur Android et iPhone.

## Utilisation

- Ajouter des contacts et, si souhaité, leur photo.
- Toucher une photo, puis confirmer l'appel. Le téléphone ouvre son composeur avec le numéro.
- Dans **Réglages**, choisir la taille des cadres et exporter/importer une sauvegarde.

Les contacts et les photos sont conservés localement sur chaque appareil, dans son navigateur. Ils ne sont jamais envoyés à GitHub.
